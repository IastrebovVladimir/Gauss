# Gauss

gaussNoPivot(double** A, double* b, int n, double* x) — решает СЛАУ методом Гаусса без выбора главного элемента, выполняя прямой ход и затем обратную подстановку.

gaussWithPivot(double** A, double* b, int n, double* x) — решает СЛАУ методом Гаусса с частичным выбором главного элемента по столбцу, что повышает численную устойчивость вычислений.

LU(double** A, double** L, int* P, int n) — выполняет LU-разложение матрицы с перестановками строк, формируя нижнюю матрицу L, верхнюю матрицу U (она хранится в A) и массив перестановок P.

LowerSubstitution(double** L, double* b, double* y, int n) — решает нижнетреугольную систему Ly=b методом прямой подстановки.

UpperSubstitution(double** U, double* y, double* x, int n) — решает верхнетреугольную систему Ux=y методом обратной подстановки.

Функция main() генерирует случайные матрицы разных размеров и две правые части, после чего сравнивает время решения системы методом Гаусса и методом LU-разложения. В программе для первой правой части измеряется время полного решения через LU, а для второй — только время решения при уже готовом LU-разложении, что позволяет показать преимущество LU при нескольких правых частях.
